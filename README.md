# VKare Digital vCard

Digital business card for **Khagendra Mahant** of **VKare Pvt Ltd**.

## Live features
- Responsive premium vCard
- Call, WhatsApp, Email and Website actions
- Save Contact (.VCF)
- Share Contact
- Registered and Branch office links
- Dark mode
- Optional LinkedIn, Google Meet and Meeting Booking links (hidden automatically when blank)
